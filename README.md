# MergeWeave GitHub App

The official GitHub App for MergeWeave. Monitor your repositories for merge conflicts and get one-click, AI-powered resolutions.

## Getting Started

### Repository Permissions

Mergeweave will request the following permissions for each repo it's installed on:
1. Read access to metadata
2. Read and write access to checks, code, commit statuses, and pull requests

### Installation Steps

1. Navigate to https://github.com/apps/mergeweave-app.
2. Click "Configure".
3. (if prompted) Choose the account you'd like to install Mergeweave on.
4. Follow the on-screen instructions until you reach the permissions/repository access screen.
5. Choose which repositories you'd like to set up Mergeweave on (either "All repositories", or you can configure select repositories). Click save.

## Support

If you run into any issues during installation, please email admin@mergeweave.ai, and we'll reach out ASAP to assist.
